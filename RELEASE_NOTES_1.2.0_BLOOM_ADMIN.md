## New Features

- **Delight Client branding.** Bloom Client has a new name and wing logo to avoid confusion with an unrelated hacked Minecraft client that uses the Bloom Client name.
- **Portal.** Find worlds and servers in separate lists, with search, filters, favorites, and direct launch.
- **Undo logout.** The account menu gives you five seconds to cancel a sign-out.

## Improvements

- Softer ceramic buttons and gentler hover feedback across instance, mod, screenshot, and Settings actions.
- Redesigned the account menu with a distinct borderless surface.
- The Windows installer preserves the existing upgrade path so accounts and instances carry over.
- This release is available for Windows. The next client update will be 1.2.1.

## Fixes

- Added Minecraft's default server icon for Portal entries without custom artwork.
- Matched the Clear cache, Change, and per-photo action buttons to the shared button style.
