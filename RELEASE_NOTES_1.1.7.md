# :BloomPetals: **Bloom Client — Patch Notes** :BloomPetals:

## **Version 1.1.7**

### **New Features**

- Added **Screenshot Shelf** to the sidebar, with screenshots from all instances, instance filtering, full-size previews, image copying, and folder shortcuts.
- Added twelve **Organic backgrounds** that follow your accent color and respect reduced-motion and performance settings.

### **Interface & Animation Improvements**

- Redesigned background controls with an image preview, clearer source selection, and independent interface and sidebar darkness, frost, outline, and text-color controls.
- Simplified instance settings with an aligned layout, styled memory slider, Java profile help, and collapsible advanced arguments.
- Clarified **Sync Across Instances** with Copy from / Copy to labels and custom information tooltips.
- Improved search-field contrast, typography, and focus animation.
- Simplified Locker loading and instance-content empty states, and improved the file-drop indicator.
- Moved screenshot copying and instance-content action feedback into the bottom notification tray.

### **Fixes**

- Fixed primary buttons and toggle states becoming too dim with custom or Organic backgrounds.
- Fixed the first Add Mods visit occasionally showing a blank catalog.
- Fixed title-bar drag coverage, segmented-tab corner artifacts, and the exposed strip beside the sponsored rail in wide windows.
- Fixed development builds checking for and attempting to install production updates. Installed release builds retain signed automatic update discovery.

*Version 1.1.7 focuses on personalization, clearer controls, and a more consistent everyday experience.* :cherry_blossom:
