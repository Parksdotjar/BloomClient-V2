# :BloomPetals: **Bloom Client — Patch Notes** :BloomPetals:

## **Version 1.1.8**

### **New Features**

- Added complete **Light mode** alongside OLED Black, including menus, dialogs, settings, and softer shadows.
- Added customizable **animated accent gradients** with up to five colors, draggable color stops, and speed and intensity controls.
- Added **Screenshot comparison** with a draggable divider, Swap, Reset, and PNG export.
- Added the **Ctrl+K quick switcher** for instances, pages, and settings.
- Added automatic **Bloom Cosmetics** integration for Fabric Minecraft **26.1, 26.2, and 26.3**, alongside 1.21.11.

### **Performance Improvements**

- Improved repeat launches with verified installation caching and parallel preparation while retaining required file checks.
- Improved screenshot loading with persistent caching and background warming.
- Improved Organic backgrounds with distinct artwork, matching thumbnails, and smoother movement that respects performance and reduced-motion settings.

### **Interface & Fixes**

- Refined the instance library with a centered heading, top creation and filter controls, and a separate bottom search bar.
- Improved content filters, account-picker alignment, and cosmetic artwork; instance downloads now display their pack artwork.
- Fixed Bloom account restoration when sharing immediately after startup, without first opening Social.
- Fixed shared Fabric packs missing loader-version metadata when an installed loader can be resolved.
- Updated the in-game **Bloom badge** to the current logo with dedicated spacing and a single name-tag layer.
- Allowed **resource packs and shaders** to install while Minecraft runs. Mods still require closing the game, and cancelling a pack download no longer cancels Minecraft.
- Replaced technical rate-limit errors with a short message asking users to try again later.
- Preserved development-mode updater isolation: local development never downloads or installs production updates.

*Version 1.1.8 focuses on personalization, faster everyday use, and smoother in-game integration.* :cherry_blossom:
